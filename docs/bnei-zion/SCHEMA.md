# בני ציון — Torah Content Engine data contract

Source: the authorized archive "בני ציון" by Moshe Mizrachi (permission granted by the author for use in this free app,
recorded 2026-10-01 by the owner). NOT public domain — a personal permission for this app.
Required credit (UI): מתוך "בני ציון" · משה מזרחי · מובא באישור בעל הזכויות

Generated runtime data lives under `src/data/torahContent/` (produced by `scripts/bnei-zion/*`, never hand-edited):

- `index.mjs` — compact index, loaded lazily by the engine:
  `export default { version, generatedAt, articles: [ { id, title, contentType, parashot:[canonical], holidays:[id],
  specialShabbatot:[id], topics:[…], readMinutes, year?, pack, excerpt } ], parashot:{name:[ids]}, holidays:{id:[ids]},
  topics:{name:[ids]} }`
- `public/torah-content/packs/<pack>.json.gz` — article bodies by pack (e.g. per parasha / holiday / general),
  `{ articles: { <id>: { text, paragraphs:[…], source:{ collection:'בני ציון', author:'משה מזרחי', originalPdf, pageStart,
  pageEnd }, sourceAppearances:[…], rights:{ permission:'granted', creditRequired:true, note:'שימוש באישור מפורש של בעל
  הזכויות' }, extraction:{ method, confidence }, status:'published' } } }` with checksums in a manifest.
- `src/data/torahContent/search.mjs` (or a gz shard) — prebuilt normalized search fields for fast offline search.

Canonical parashot (56 names as in the owner's list, e.g. תצווה, בחוקותי, קורח, חוקת, פינחס, ניצבים, כי תבוא) with an
alias map; holiday ids (rosh-hashana, yom-kippur, sukkot, hoshana-rabba, shmini-atzeret, simchat-torah, chanukah,
tu-bishvat, purim, pesach, seventh-pesach, pesach-sheni, lag-baomer, shavuot, three-weeks, tisha-bav, …) and special
Shabbat ids (shabbat-shekalim, shabbat-zachor, shabbat-parah, shabbat-hachodesh, shabbat-hagadol, shabbat-shuva,
shabbat-chazon, shabbat-nachamu) — only those with real material.

## App-side notes (agent B — the engine in `src/services/torahContent.mjs`, `torahSelection.mjs`, `torahSearch.mjs`)

Added 2026-10-01 by the app side; please keep these or tell us if you change them.

- **Pack manifest** — preferred inside the index: `index.packs = { <pack>: { file: '<pack>.json.gz', checksum } }`.
  If absent, the app reads `public/torah-content/packs/manifest.json` (`{ packs: { <pack>: { file, checksum } } }`);
  without either it loads `<pack>.json.gz` unverified. `checksum` = FNV-1a 32-bit hex (`src/services/prayer/checksum.mjs`)
  of the **decompressed** JSON text, exactly as the library packs.
- **`contentType`** vocabulary the weekly selection understands: `short`, `deep`, `story`, `family`, `children`, `halacha`,
  `musar`, `question`, `article`. The three weekly places are short / deep / story-or-family (`readMinutes` decides
  when the type is not one of these). Unknown values show as "דבר תורה".
- **`parashot`** may use any spelling — the app maps variants (תצוה/תצווה, קרח/קורח, Hebcal transliterations) to its 54
  canonical names (`src/services/torahTaxonomy.mjs`). An article on a combined reading lists both halves.
- **`search.mjs`**: `export default { version, docs: [ { id, t, m, x } ] }` — `t` the title, `m` parasha / holiday /
  topics / keywords / source, `x` the body; each already passed through `normalizeHebrew` (`src/content.mjs`).
  Optional: without it the app searches titles, metadata and excerpts only.
- **`status`** in a pack other than `'published'` is never shown. `rights.permission` must be `'granted'` and
  `rights.creditRequired: true` (checked by `validatePack`).
- Where the archive has nothing for a parasha or festival, the app shows its own three (`src/data/divreiTorah.mjs`),
  marked `collection: 'app'` and never credited to בני ציון.
- Test fixture of this contract: `tests/fixtures/torahContentSample/` (placeholder text "דוגמה לבדיקה"; never shipped).

## As generated by the ingestion pipeline (`scripts/bnei-zion/`, full archive, 2026-10-01)

Refinements of the contract above, implemented and checked by `tests/bneiZionData.test.mjs`. Where they differ from the
text above, **this section wins**.

- **ids** — `bz-<10 hex>`, from the article's normalised unpointed text: stable across rebuilds while the text is unchanged.
- **index.mjs** (`src/data/torahContent/index.mjs`, lazy chunk) — `{ version, generatedFrom, pilot, collection, author,
  credit, articles, parashot, holidays, specialShabbatot, topics, packs, search }`.
  - An article entry: `{ id, title, heading?, contentType, length, parashot, holidays, specialShabbatot, topics,
    readMinutes, year?, shabbatTable?, pack, excerpt }`.
  - `title` — the SHORT title (owner's decision): 2–6 of the author's own words, unpointed — the key phrase of the
    heading's quotation (a verse's speech formula such as "ויאמר ה' אל משה" skipped), or the heading itself when short, or
    the piece's opening words when it has no heading.
  - `heading` — the author's full heading line, exact (with its points and source reference); present when it differs
    from the title. Show it as the first line under the title. The same `heading` is also in the pack body.
  - `length` — `short` (≤ 3 min) · `medium` · `long` (≥ 8 min). `readMinutes` at 150 words/minute (pointed text).
  - `year` — the earliest Hebrew year the piece was printed (e.g. `תשע״ו`). `shabbatTable: true` — a story or mashal of
    ≤ 3 minutes, suitable "לשולחן שבת". `excerpt` — the opening ~100 characters, unpointed.
  - `parashot` / `holidays` / `specialShabbatot` / `topics` at the top level are **counts** (`{ name: n }`), not id lists —
    the engine builds its own lists from the entries (keeps the module small).
  - `packs: { <name>: { file, checksum, articles } }`; `search: { file: 'search.json.gz', path: 'torah-content/search.json.gz',
    checksum, docs }`. Checksums are FNV-1a of the decompressed JSON text (`src/services/prayer/checksum.mjs`).
- **contentType** — `dvar-torah`, `story`, `mashal`, `chizuk`, `commentary`, `family`, `general`
  (labels: דבר תורה, סיפור, משל, חיזוק, פירוש, לשולחן המשפחה, כללי).
- **topics** — only from the owner's list; at most three, often none.
- **Assignment** — parashot are the canonical names of `torahTaxonomy.mjs`; a double week (ויקהל-פקודי …) lists both. A
  combined issue (נשא-שבועות, מקץ (חנוכה), יום הכיפורים-האזינו …) is separated piece by piece: parasha only, festival
  only, or both when the piece genuinely belongs to both. Special Shabbatot are added to the regular parasha, never
  instead of it. Holiday ids used: `rosh-hashana, yom-kippur, sukkot, hoshana-rabba, shmini-atzeret, simchat-torah,
  chanukah, tu-bishvat, purim, pesach, seventh-pesach, lag-baomer, shavuot, three-weeks, elul`.
- **וזאת הברכה** — read on שמחת תורה. A שמחת תורה piece that speaks of the parasha (its verses, Moshe's blessing or
  passing, finishing the Torah) carries parasha `וזאת הברכה` as well as holiday `simchat-torah`. **The וזאת הברכה
  collection shown by the engine = articles with parasha `וזאת הברכה` ∪ articles with holiday `simchat-torah`.**
- **ט״ו בשבט** — a piece of the weeks בא / בשלח / יתרו that speaks of ט״ו בשבט carries holiday `tu-bishvat` in addition to
  its parasha.
- **Not published** — statements and announcements in the general folder (a 2016 protest statement and the "ספר תורה
  לכבוד דוד המלך" appeal/poster) are rejected as not Torah.
- **packs** (`public/torah-content/packs/<name>.json.gz`) — one per parasha (`bereshit`, `yitro`, … in Torah order), per
  festival id (`pesach`, `shavuot`, `elul`, …), plus `special-shabbatot` / `general`. A piece with a festival lives in the
  festival's pack, otherwise in its (first) parasha's. Body: `{ heading, paragraphs, source: { collection, author,
  originalPdf, pageStart, pageEnd, year? }, sourceAppearances: [{ originalPdf, pageStart, pageEnd, year?, date? }],
  rights, extraction: { method, confidence }, status: 'published' }` — no `text` (it is `paragraphs.join('\n\n')`).
  Each pack JSON also carries `generated` (the generated-file notice).
- **search** — `public/torah-content/search.json.gz` (gzip of JSON), fetched lazily on the first search, never at launch:
  `{ generated, version, docs: [{ id, t, m, x }] }`, all normalised with `normalizeHebrew` (unpointed): `t` = short title +
  heading, `m` = parashot (+ "פרשת X"), festival and special-Shabbat names, topics, type label, "בני ציון משה מזרחי", year;
  `x` = the piece's distinct words. Verify with `manifest.search.checksum` (or `index.search.checksum`) after decompressing.
  The old `src/data/torahContent/search.mjs` module is no longer generated.
- **manifest** (`public/torah-content/packs/manifest.json`) — `{ generated, version, packs: { <name>: { file, checksum,
  sha256, bytes, raw, articles } }, search: { file, path, checksum, sha256, bytes, raw, docs } }`.
- Only `published` pieces ship; `review` / `rejected` stay in the pipeline's work files and are listed in `coverage.md`.
- Text is exactly as printed, including the niqqud; only leaflet chrome (headers, times, contact lines, page numbers, rules,
  hidden white text, closing greetings) and — owner's rule — sentences with private phone numbers / e-mail addresses are
  removed. A shorter printing contained in a longer one is merged into it; a piece cut off mid-sentence in the source is
  rejected.
