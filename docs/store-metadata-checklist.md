# Store Metadata Checklist

## Identity

- [ ] Final app name, subtitle/short description, category, developer identity, support URL, and privacy-policy URL.
- [ ] Final bundle identifier and Android application ID.
- [ ] Confirm rights to brand, logo, memorial imagery, screenshots, and all store artwork.
- [ ] Include the existing non-affiliation statement for Sefaria, Koren, and Steinsaltz.

## Product

- [ ] Hebrew and English metadata reviewed by a human.
- [ ] Screenshots show the real app on phone and tablet-sized layouts.
- [ ] Review notes explain sunset-aware Hebrew dates, optional location, offline shell, remote source attribution, and no-login behavior.
- [ ] No placeholder content, dead links, or unsupported claims.

## Privacy and legal

- [ ] Publish the privacy policy and use the same URL in both stores.
- [ ] Submit data-safety/privacy answers from the final native permissions and plugins.
- [ ] Complete [content license register](content-licenses.md), including commercial-use confirmation.
- [ ] Confirm external provider terms and required attribution.

## QA and release

- [ ] Test fresh install, upgrade, offline startup, network recovery, denied location, manual city search, deep links, back navigation, RTL, Dynamic Type, VoiceOver/TalkBack, rotation, and tablet layouts.
- [ ] Verify app icons, launch assets, version/build numbers, signing, crash reporting policy, and release channels.
- [ ] Prepare reviewer access instructions; no demo account is needed if the final product remains account-free.
